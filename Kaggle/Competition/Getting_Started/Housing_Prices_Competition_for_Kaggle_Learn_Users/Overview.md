### Description

#### Competition Description

让一位房产买家描述他们的理想住宅，他们可能不会从地下室天花板的高度或靠近东西方向铁路这一点入手。不过，这项游乐场竞赛的数据集表明，在价格谈判中，许多因素比卧室数量或白色的栅栏围栏更为重要。  

在这个比赛中，有 **79** 个解释性变量用于描述爱荷华州艾姆斯市住宅的几乎所有方面。**你的任务是预测每套住宅的最终售价。**

#### Practice Skills   

- 创造性的特征工程设计
- 先进的回归技术，如随机森林和梯度提升算法  

### Evaluation    

#### Goal  
你的任务是对每栋房子的售价进行预测。对于测试集中的每一栋房子，你需要预测 SalePrice 这个变量的数值。  

#### Metric  

提交的预测值会根据预测值对数与观测到的销售价格对数之间的均方误差来进行评估。（之所以采用对数形式，是为了让预测昂贵房屋和廉价房屋时的误差对结果产生同等的影响。）   

#### Submission File Format  

该文件应包含头部信息，并且格式必须符合以下要求：  

```python
Id,SalePrice
```  
