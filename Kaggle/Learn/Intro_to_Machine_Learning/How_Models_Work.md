#### 你的表亲通过投机房地产赚了数百万美元。由于你对数据科学感兴趣，他提出要和你成为商业伙伴。他出钱，你提供模型来预测各种房屋的价值。  
你问表亲过去是如何预测房地产价值的，他说全靠直觉。但进一步询问后发现，他从过去见过的房屋中识别出了价格模式，并用这些模式来预测他正在考虑的新房屋。  
机器学习的工作方式也是如此。我们将从一种称为决策树的模型开始。有些更高级的模型能给出更准确的预测。但决策树易于理解，而且它们是数据科学中一些最佳模型的基本构建模块。  
为简单起见，我们先从最简单的**决策树**开始。  
它只把房屋分成两个类别。对于任何正在考虑中的房屋，其预测价格就是同一类别中房屋的历史平均价格。
我们使用数据来决定如何将房屋分成两组，然后再用数据确定每个组中的预测价格。这个从数据中捕捉模式的步骤称为**拟合或训练模型**。用于拟合模型的数据称为**训练数据**。
模型如何拟合的细节（例如如何划分数据）足够复杂，我们会留到后面再讲。模型拟合完成后，你可以把它应用于新数据，以预测其他房屋的价格。
你通过沿着决策树追踪来预测任何房屋的价格，始终选择与该房屋特征相对应的路径。该房屋的预测价格位于树的底部。我们在底部做出预测的那个点称为**叶子**。
分裂方式以及叶子处的取值将由数据决定，所以现在该你去查看将要使用的数据了。  
  
“模式”在这里不是玄学，也不是指某一个具体房子的价格，而是指：**从多个样本中反复出现、可以用特征解释、并且能用于预测新样本的规律或统计关系。**  更准确地说，在机器学习语境中，“模式”可以定义为：**数据中特征与目标变量之间稳定的关联结构或规律性。它表现为：当某些特征取特定值或落入特定范围时，目标变量的取值或分布呈现出可重复的趋势。**  
  
- 机器学习：让计算机从数据中自动捕捉模式，并利用这些模式对新样本进行预测或决策的方法。  
- 模型：从输入特征到预测目标之间的映射关系或规则集合。  
- 决策树：一种树形预测模型：通过一系列分裂条件把样本逐步分组，最终在叶子节点给出预测值。  
- 拟合 / 训练：利用训练数据确定模型结构和参数的过程。拟合与训练在本课程中基本同义。
- 训练数据：用于拟合模型的数据集。
- 特征：描述样本的输入变量。
- 目标变量 / 标签：模型要预测的变量。
- 预测：模型对新样本输出目标变量估计值的过程。
- 分裂：在决策树中，根据某个特征的条件把当前样本集合划分为两个或多个子集的操作。
- 根节点：决策树最顶端的节点，是第一次分裂发生的位置。
- 内部节点：决策树中非叶子的节点，通常包含一个分裂条件。
- 叶子 / 叶节点：决策树中不再继续分裂的终端节点，负责给出最终预测值
- 路径：从根节点到某个叶子节点所经过的一系列分裂条件。
- 树的深度：决策树中从根节点到最深叶子的层数或分裂次数。深度越大，树通常越“深”。
- 类别 / 分组：按某种规则把样本划分成的子集。
- 回归：预测连续数值目标的机器学习任务。
