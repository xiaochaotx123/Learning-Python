### 一、基础访问方式
#### 1.直接通过索引标签访问
类似于字典的访问方式
```python
import pandas as pd

s = pd.Series([10, 20, 30, 40], index = ["A", "B", "C", "D"])

# 访问单个元素
print(s["B"]) # 输出：20

# 访问多个元素（传入列表）
print(s[["A", "C"]])
# 输出：
"""
A    10
C    30
dtype: int64
"""
```

#### 2. 通过位置（整数）访问
类似于列表的访问方式
```python
# 当问单个元素（第2个）
# print(s["B"]) # 输出：20

# 访问多个元素
# print(s[[0, 2, 3]]) 
# 输出：[10 20 40]
"""
A    10
B    20
D    40
dtype: int64
"""

# 但是这种方式需要满足没有index，如果有index，则需要通过index来访问
```
### 二、切片访问
#### 3. 标签切片（包含终点） 
```python
print(s["B" : "D"])
# 输出：
"""
B    20
C    30
D    40
dtype: int64
"""
```

#### 4. 位置切片（不包含终点）
注意，直接使用这种数字访问元素或者切片，必须是没有自定义index，否则会报错！

三、布尔索引（条件筛选）
这是最最强大的访问方式之一，可以根据条件筛选数据

#### 5. 单条件筛选
```python
print(s[s > 20])
# 输出：
"""
C    30
D    40
dtype: int64
"""
```

#### 6. 多条件筛选
使用 &（与），|（或），~（非），每一个条件必须加括号
```python

# 大于 15 并且小于 40
print(s[(s > 15) & (s < 40)])
# 输出：
"""
B    20
C    30
dtype: int64
```
