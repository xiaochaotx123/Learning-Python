### 题目一：销售数据分析
场景：某公司销售数据如下，请完成以下任务：
- 计算每种产品的总销售额（销售额 = 单价 × 数量）
- 找出销售额最高的产品
- 按销售额从高到低排序，并输出所有产品信息
```python
data = {
    "产品名称" : ["A", "B", "C", "D"],
    "单价" : [100, 150, 200, 120],
    "销量" : [50, 30, 20, 40],
}
```

```python
import pandas as pd
```
```python
sell = pd.DataFrame(data)
#   产品名称   单价  销量
# 0    A  100  50
# 1    B  150  30
# 2    C  200  20
# 3    D  120  40
```


#### 计算每种产品的总销售额（销售额 = 单价 × 数量）
```python
sell["销售额"] = sell["单价"] * sell["销量"]
print(sell)
# 输出：
#   产品名称   单价  销量   销售额
# 0    A  100  50  5000
# 1    B  150  30  4500
# 2    C  200  20  4000
# 3    D  120  40  4800
```

#### 找出销售额最高的产品
```python
print(sell.nlargest(1, ["销售额"]))
```

#### 按销售额从高到低排序，并输出所有产品信息
```python
sorted_sell = sell.sort_values(by = ["销售额"], ascending = [False])
print(sorted_sell)
# 输出：
#   产品名称   单价  销量   销售额
# 0    A  100  50  5000
# 3    D  120  40  4800
# 1    B  150  30  4500
# 2    C  200  20  4000
```
