### 什么是箱型图
箱型图利用数据中的五个统计量（最小值、下四分位数、中位数、上四分位数、最大值）来描述数据的分布情况。因为它形状像一个带有胡须的箱子，所以被称为箱型图。  
- 中位数（Q2）：数据的中心点，代表一般水平。
- 四分位数（Q1和Q3）：将数据按大小等分为四份，Q1是25%位置，Q3是75%位置。Q1到Q3构成了“箱子”的上下边界。
- 四分位距（IQR）：Q3 - Q1，代表了数据中间50%的集中程度。
- 上下边缘线（触须）：通常是 Q3 + 1.5 × IQR 和 Q1 - 1.5 × IQR 范围内的最大/最小真实数据点。
- 异常值（Outliers）：超出上下边缘线的数据点，通常用圆点单独标出。

#### 导入库 
```python
import matplotlib.pyplot as plt
```

#### 箱型图的数据  
```python
data = {
    "语文" : [82, 85, 88, 70, 90, 76, 84, 83, 95],
    "数学" : [75, 80, 79, 93, 88, 82, 87, 89, 92],
    "英语" : [70, 72, 68, 65, 78, 80, 85, 90, 95]
}
```

#### 绘制箱型图  
```python
plt.figure(figsize = (8, 6))
plt.boxplot(data.values(), tick_labels = list(data.keys()))

plt.title("各科成绩分布（箱型图）")
plt.ylabel("分数")
plt.grid(True, axis = "y", linestyle = "--", alpha = 0.5)
plt.xlabel("科目", fontsize = 20)
plt.ylabel("分数", fontsize = 20)
plt.xticks(rotation = 0, fontsize = 15)
plt.yticks(rotation = 0, fontsize = 15)
plt.show()
```
