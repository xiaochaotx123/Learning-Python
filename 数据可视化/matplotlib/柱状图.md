### 导入库
```python
import matplotlib.pyplot as plt
from matplotlib import rcParams
rcParams["font.family"] = "SimHei"
```

### 设置图标
```python
plt.figure(figsize = (10, 5))
```

### 绘图数据
```python
subject = ["语文", "数学", "英语", "科学"]
scores = [85, 92, 78, 88]
```

### 绘制柱状图
```python
plt.bar(
    subject, scores,
    color = "orange",
    alpha = 0.8,
    label = "小超",
    width = 0.5
)
```
- plt.bar() 是 Matplotlib 中用来绘制垂直柱状图的函数，常用于比较不同类别的数值大小。   

```python
plt.title("2025年成绩分布", fontsize = 20, color = "red")
plt.xlabel("科目", fontsize = 15)
plt.ylabel("分数", fontsize = 15)
plt.legend(loc = "upper left")
plt.grid(axis = "y", color = "black", alpha = 0.3)
plt.xticks(fontsize = 15)
plt.yticks(fontsize = 15)
plt.ylim(0, 100)
for x, y in zip(subject, scores) :
    plt.text(x, y + 1, str(y), ha = "center", va = "bottom", fontsize = 10)
```

#### 自动优化排版  
```python
plt.tight_layout()
```
- plt.tight_layout() 用于自动调整子图布局，让子图之间、子图与画布边缘之间保持合适间距，从而避免坐标轴标签、标题、刻度标签互相重叠或被裁剪。  


#### 输出图表
```python
plt.show()
```
