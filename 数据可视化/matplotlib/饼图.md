### 导入库
```python
import matplotlib.pyplot as plt
from matplotlib import rcParams
rcParams["font.family"] = "SimHei"
```

### 创建图表  
```python
plt.figure(figsize = (10, 5))
```

### 图表数据  

#### 一般的参数

```python
things = ["学习", "娱乐", "运动", "睡觉", "其他"]
times = [6, 4, 1, 8, 5]
```

#### 自定义颜色
```python
colors = ["orange", "yellow", "pink", "green", "gray"]
```

#### 绘制爆炸式饼图（突出某部分）
```python
explode = [0.1, 0, 0, 0, 0] # 设置突出块的参数
```

### 绘制图表
```python
plt.pie(
    times, labels =  things,
    autopct = "%.2f%%", # 显示百分比
    startangle = 90, # 调整起始绘图角度，默认是0度（x正半轴）逆时针旋转开始填充数据
    colors = colors, # 设置饼图的颜色
    wedgeprops = {"width" : 0.6}, # 设置圆环的宽度
    pctdistance = 0.7, # 设置百分比数字的位置
    explode = explode,
    shadow = True,
)
```
- plt.pie()是画一个环形图
- times：每个扇区对应的数值（大小），会自动归一化算占比。
- things：每个扇区的标签，可以传列表。
- autopct="%.2f%%"：自动在扇区上显示百分比。"%.2f%%" 表示保留两位小数并带 % 号
- startangle=90：设置起始绘制角度。默认是 0 度，即从 x 轴正半轴开始，逆时针填充。
- colors=colors：传入颜色列表，依次对应每个扇区。
- wedgeprops={"width": 0.6}：相当于设置环形图，中间挖空一部分
- pctdistance=0.7：百分比文字距离圆心的半径比例。
- explode=explode：让指定扇区从圆心向外偏移，形成"突出"效果。explode 是一个与扇区数量相同的列表，每项是偏移比例
- shadow=True：给饼图添加阴影，增加立体感。属于装饰性参数，正式图表中可视风格决定是否使用。
