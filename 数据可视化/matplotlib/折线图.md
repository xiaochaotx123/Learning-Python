### 导入库

#### 导入绘图库
```python
import matplotlib.pyplot as plt
```
- matplotlib：Python最常用的绘图库，支持折线图、柱状图、散点图、饼图、直方图等
- matplotlib.pyplot：matplotlib下面的一个子模块，提供了一套类似MATLAB的绘图命令

#### 设置中文
因为matplotlib默认字体是英文字体，不支持中文，导致图表中出现中文乱码问题。所以修改字体
```python
from matplotlib import rcParams
rcParams["font.family"] = "SimHei"
```
- rcParams是matplotlib的全局配置对象。控制绘制图的各种默认行为：字体、字号、颜色、线条粗细、图例位置、保存分辨率等
- font.famlily：字体族
- SimHei：Windows自带的黑体字体名
设置之后所有的绘图的中文都会用SimHei渲染

### 创建画布，设置大小
```python
plt.figure(figsize = (10, 5))
```
- plt.figure()：创建一个新的图形/画布对象
- figsize = (10, 5)：设置画布的尺寸：宽10英尺，高5英尺
这行代码的意思是新建一个宽10英尺、高5英尺的画布，后面的plt.plot()、plt.title()等都会画在这张画布上

#### figsize = (宽, 高)
单位是英寸(inch)，不是像素  
必须是元组或列表，例如(10, 5)、[10, 5]  
实际像素取决于 dpi
```python
像素宽 = figsize[0] * dpi
像素高 = figsize[1] * dpi
```
matplotlib默认 dpi = 100，所以:
```python
plt.figure(figsize=(10, 5))
# 实际显示/保存约为 1000 × 500 像素
```
如果想要提升清晰度，设置dpi即可：
```python
plt.figure(figsize=(10, 5), dpi=150)
# 1500 × 750 像素
```

### 绘图的数据
```python
month = ["1月", "2月", "3月", "4月"]
sales = [100, 150, 80, 130]
```
x数据个数必须与y的数据个数相等，否则报错 

当x轴是字符串时，matplotlib会把它们当作分类标签处理，均匀的排布在x轴上  
当x轴是数值时，会按数值的大小比例分布在x轴上。如果数值是[1, 2, 100]，那么2和100之间的间距就会非常大  
y轴一律是数值。如果是字符串，会报错  

### 绘制折线图
#### plt.plot()
·```python
plt.plot(
    month, sales,
    label = "产品A",
    color = "orange",
    linewidth = 2,
    linestyle = "--",
    marker = "o"
)
```
plt.plot()函数整体结构是：
```python
plt.plot(x, y, **样式参数)
```
- x：x轴数据，这里传入month（月份列表）
- y：y轴数据，这里传入sales（销售额列表）
- label = "产品A"：给这条线起一个名字，需要搭配plt.legend()才会显示，否则这个参数不起作用
- color = "orange"：设置线条颜色
- linewidth = 2：设置线条粗细
- linestyle = "--"：设置线条样式

|取值|效果|
|----|----|
|"-"|实线（默认）|
|"--"|虚线|
|"-."|点画线|
|":"|点线|
|""|不画线|

- marker = "o"：设置数据点标记，"o"是圆点
  
|取值|效果|
|---|----|
|"o"|圆点|
|"s"|正方形|
|"^"|上三角|
|"v"|下三角|
|"D"|菱形|
|"*"|星号|
|"+"|加号|
|"x"|叉号|
|"."|小圆点|

#### 添加标题
```python
plt.title("2025年销售趋势", fontsize = 30)
```
- plt.title()：给当前图表添加一个标题。
- fontsize = 30：设置标题字号为 30
- color = ""：设置标题颜色

#### 添加坐标轴标签
```python
plt.xlabel("月份", fontsize = 20)
plt.ylabel("销售额（万元）", fontsize = 20)
```
- plt.xlabel()：给x轴（水平轴）添加标签，显示在轴下方
- plt.ylabel()：给y轴（垂直轴）添加标签，显示在轴左侧

#### 添加图例
```python
plt.legend(loc = "upper left")
```
图例（Legend）就是图表中那个小方块说明框，告诉读者每种颜色/线条代表什么数据。  
每条线的名字来自 plt.plot(..., label="产品A") 里的 label 参数。  
plt.legend() 的作用就是把这些 label 收集起来，画成一个说明框  
写了 label 不调 plt.legend()，图例不会出现；调了 plt.legend() 但没写 label，图例是空的。
- loc = "upper left"：图例的位置：左上角

|取值|位置|
|---|-----|
|"best"|自动选择最不挡数据的位置（默认）|
|"upper right"|右上角|
|"upper left"|左上角|
|"lower left"|左下角|
|"lower right"|右下角|
|"center"|正中央|
|"center left"|左侧中间|
|"center right"|右侧中间|
|"upper center"|上方中间|
|"lower center"|下方中间|


#### 添加网格线
```python
# plt.grid(True) # 表示x轴和y轴都设置网格线
# plt.grid(axis = "x") # 使用axis参数表示只设置x轴网格线或者只设置y轴网格线
plt.grid(True, alpha = 0.9, color = "green", linestyle = "--")
```
- plt.grid()：给当前坐标轴添加/控制网格线
- True：显示网格线，是x轴网格线和y轴网格线都显示
- alpha = 0.9：设置网格线的透明度
- color = "green"：设置网格线的颜色
- linestyle = "--"：设置网格线的样式

如果只需要设置x和y其中一条网格线，使用axis参数
```python
plt.grid(True, axis="x")   # 只画 x 轴方向的竖线
plt.grid(True, axis="y")   # 只画 y 轴方向的横线
plt.grid(True, axis="both")  # 两个方向都画（默认）
```

#### 设置刻度字体大小
```python
plt.xticks(fontsize = 15)
plt.yticks(fontsize = 15)
```
- plt.xticks()：控制 x 轴上的刻度位置和刻度标签
- plt.yticks()：控制 y 轴上的刻度位置和刻度标签
- fontsize = 15：设置刻度标签的字号

当轴刻度文字太长或太密，会互相重叠。旋转一下就能拉开。使用rotation参数，旋转刻度文字  
按照逆时针旋转字体
```python
plt.xticks(rotation=45, fontsize=12)     # 逆时针 45°
plt.xticks(rotation=90, fontsize=12)     # 竖排
plt.xticks(rotation=-30, fontsize=12)    # 顺时针 30°
```

#### 手动设置y轴的显示范围
```python
plt.ylim(0, 160)
```
- plt.ylim()：设置 y 轴（Y-Limit）的上下限
- 0：y 轴下端从 0 开始
- 160：y 轴上端到 160 结束
效果：y 轴只会显示 0 到 160 之间的区域，低于 0 或高于 160 的部分会被裁掉。


#### 在每一个数据点旁显示具体数据值
```python
for x, y in zip(month, sales) :
    plt.text(x, y + 2, str(y), ha = "center", va = "bottom", fontsize = 15)
```
- zip(month, sales)： 把两组数据配对
- plt.text()：是在图表的指定坐标处写一段文字。
- x, y + 2：文字位置：x 用月份，y 用数值上移 2 个单位
- str(y)：文字内容：把数字转成字符串
- ha = "center"：水平居中对齐
- va = "bottom"：垂直方向以底部对齐
- fontsize = 15：字号

plt.show()
