### 导入库
```python
import matplotlib.pyplot as plt
from matplotlib import rcParams
rcParams["font.family"] = "SimHei"
```

### 设置图表
```python
plt.figure(figsize = (10, 5))
```

### 图表数据
```python
countrys = ["China", "Japan", "American", "English", "India"]
GDPs = [130, 30, 140, 90, 50]
```

### 绘制图表
```python
plt.barh(
    countrys, GDPs,
    color = "orange",
    alpha = 0.8,
    label = "不同国家的GDP数据",
)
```
- plt.barh() 用于绘制水平条形图（横向柱状图），和 plt.bar() 对应，只是把柱子的方向从垂直改成了水平。它特别适合类别名称较长、或者类别数量较多的场景。

```python
plt.xlabel("GDP", fontsize = 15)
plt.ylabel("国家", fontsize = 15)
plt.xticks(fontsize = 15)
plt.yticks(fontsize = 15 )
plt.xlim(0, 150)
plt.legend(loc = "upper right")
for x, y in zip(countrys, GDPs) :
    plt.text(y + 4, x, str(y), ha = "center", va = "bottom", fontsize = 10 )
```

- 这个 plt.text()与 plt.bar() 略有区别

### 显示图表

```python
plt.show()
```
