### 导入库  
```python
import random
import matplotlib.pyplot as plt
from matplotlib import rcParams

rcParams["font.family"] = "SimHei"
```

### 创建图表，设置大小  
```python
plt.figure(figsize = (10, 5))
```

### 绘制图的数据  
```python
x = []
y = []

for i in range(1, 201, 1):
    tmp = random.uniform(0, 10)
    x.append(tmp)
    tmp2 = 2 * tmp + random.gauss(0, 2)
    y.append(tmp2)
```  

### 绘制散点图   

#### plt.scatter()
```python
plt.scatter(x, y,
            color = "black", # 设置颜色
            alpha = 0.7, # 设置透明度
            s = 10, # 设置散点的大小
            label = "数据随机关系")
```
plt.scatter()是Matplotlib 中用来画散点图的函数，常用于展示两个变量之间的关系、数据分布或聚类效果  

#### 已经学过了基本操作
```python
plt.title("X变量和Y变量的关系", color = "red", alpha = 0.5, fontsize = 20)
plt.xlabel("X自变量", fontsize = 15)
plt.ylabel("Y自变量", fontsize = 15)
plt.legend(loc = "best", fontsize = 15)
plt.grid(True, alpha = 0.3, color = "blue", linestyle = "--")
plt.xticks(rotation = 0, fontsize = 13)
plt.yticks(rotation = 30, fontsize = 13)
plt.xlim(0, 10)
plt.ylim(0, 20)
```

#### 显示图表  
```python
plt.show()
```
