### 从键盘输入带分界符的字符串，删除所有的空白字符（ \t\n\r\f\v）。 

删除空白，但是空白字符至少有 6 种（空格、\t、\n、\r、\f、\v），而且实际场景中空白字符的种类可能更多（比如全角空格、不间断空格 \xa0）。  

而正则表达式，它提供了一种"模式"来描述"什么算空白"，用一个符号 \s 就能代表所有空白字符。这样一行代码就能全删掉。     

正则表达式是一门"描述字符串模式"的微型语言。你不用写"删掉空格、删掉换行、删掉制表符……"，而是写一个模式说"凡是符合空白特征的字符，都删掉"。  


|符号|匹配什么|等价于|
|----|-------|------|
|\s|任意一个空白字符|空格、\t、\n、\r、\f、\v 等|
|\S|任意一个非空白字符|字母、数字、标点等|



#### re 库
re 是 Python 自带的正则库，专门处理正则表达式。用之前必须先导入：  
```python
import re 
```   

#### re.sub() 函数  
re.sub() = "找到匹配的内容，替换成别的东西"。  
```python
re.sub(pattern, repl, string)
#         ↑       ↑      ↑
#      找什么   换成啥   在哪个字符串里找
```
- pattern：正则模式（要找什么），如 \s
- repl：替换成什么，本关替换成空字符串 '' = 删除
- string：原始字符串   


```python
result = re.sub(r'\s', '', s)
#                   ↑    ↑
#               找空白  换成空=删掉
```
r'\s' 前面的 r 表示原始字符串（raw string），意思是"别把 \ 当转义符处理，就当成字面的反斜杠 + s"。写正则时养成加 r 的习惯，避免反斜杠被 Python 提前转义掉。


```python
import re
import ast

s = input()
s =  ast.literal_eval(s)

s = re.sub(r'\s', '', s)
print(s)
```
