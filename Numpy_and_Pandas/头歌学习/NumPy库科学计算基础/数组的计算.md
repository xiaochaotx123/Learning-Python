### 从键盘输入一个列表和一个元组，元素长度都为4，列表与元组中间以英文逗号分隔。 

#### （1）将列表和元组分别转换成2行2列的二维数组A和二维数组B，并输出。 
#### （2）计算并输出数组A各个元素的平方根。
#### （3）计算并输出数组B各个元素的自然对数，并四舍五入保留3位小数。

```python
import numpy as np
import ast

data = input().strip()

# 输入的data是一个字符串，根据题目的要求是前面一个列表，然后中间一个逗号，最后一个元组
# 使用ast.literal_eval()可以将这个字符串处理成一个元组（因为中间是用逗号隔开的）
tup = ast.literal_eval(data)

# 处理成元组后，直接赋值即可
lst, tup = tup

A = np.array(lst)
B = np.array(tup)

A = A.reshape(2, 2)
B = B.reshape(2, 2)

print(A)
print(B)

print(np.sqrt(A))

print(np.round(np.log(B), 3))
```
