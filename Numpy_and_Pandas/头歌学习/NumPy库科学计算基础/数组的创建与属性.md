#### ast.literal_eval()
`ast.literal_eval()` 是 Python 标准库 ast（抽象语法树）模块中的一个函数，你可以把它理解为一个安全版的 eval()。它的核心作用是安全地将字符串形式的 Python 字面量（literal）转换成对应的 Python 对象，同时杜绝了代码执行的风险。  

```python
import numpy as np
import ast

arr = input().strip()

lst = ast.literal_eval(arr)
arr = np.array(lst)

print(arr)
print(arr.shape)
print(arr.size)
print(arr.dtype)
```
