### 从键盘输入一个二维列表，长度为N，每个列表元素又包含N个数值。  

#### （1）将二维列表转换成二维数组A，输出A。
#### （2）输出对角线上的元素  
#### （3）切片取最后1行。  
#### （4）切片取最后2列。 

```python
import numpy as np
import ast

data = input().strip()
lst = ast.literal_eval(data)

A = np.array(lst)

# 输出数组 A
print(A)

# 输出对角线元素
for i in range(len(A)):
    print(A[i, i], end = " ")
print()

# 切片取最后 1 行
print(A[-1])

# 切片取最后 2 列
print(A[:, -2:])
```
