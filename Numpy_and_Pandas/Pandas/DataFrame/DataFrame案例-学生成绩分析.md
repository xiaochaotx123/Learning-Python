 场景：某班级的学生成绩数据如下，请完成以下任务：  
- 计算每位学生的总分和平均分
- 找出数学成绩高于90分或英语成绩高于85分的学生
- 按总分从高到低排序，并输出前3名学生
```python
data = {
    "姓名" : ["张三", "李四", "王五", "赵六", "钱七"],
    "数学" : [85, 92, 78, 88, 95],
    "英语" : [90, 88, 85, 92, 80],
    "物理" : [75, 80, 88, 85, 90],
}
```

```python
import pandas as pd
```
```python
scores = pd.DataFrame(data)
#    姓名  数学  英语  物理
# 0  张三  85  90  75
# 1  李四  92  88  80
# 2  王五  78  85  88
# 3  赵六  88  92  85
# 4  钱七  95  80  90
```

#### 计算每位学生的总分和平均分
在Pandas中，axis用来指定操作沿着哪个方向进行。DataFrame是二维表格，有行有列两个维度，所以axis主要有两个取值
- axis = 0：沿着行的方向，对每一列进行操作
- axis = 1：沿着列的方向，对每一行进行操作


```python
# 1. 首先获取数学，英语，物理这三列的数据
# print(scores[["数学", "英语", "物理"]])
# 输出：
#    数学  英语  物理
# 0  85  90  75
# 1  92  88  80
# 2  78  85  88
# 3  88  92  85
# 4  95  80  90

# 2. 直接对每一行的元素进行处理累加 axis = 1
# print(scores[["数学", "英语", "物理"]].sum(axis = 1))
# 输出：
# 0    250
# 1    260
# 2    251
# 3    265
# 4    265
# dtype: int64
# test = scores["数学"] + scores["英语"] + scores["物理"]也是可以的


# 3. 最后在scores中可以新创建一个总分的columns
scores["总分"] = scores[["数学", "英语", "物理"]].sum(axis = 1)
# print(scores)
# 输出：
#    姓名  数学  英语  物理   总分
# 0  张三  85  90  75  250
# 1  李四  92  88  80  260
# 2  王五  78  85  88  251
# 3  赵六  88  92  85  265
# 4  钱七  95  80  90  265


# 4. 计算平均分是一样的
scores["平均分"] = round(scores["总分"] / 3, 3)
# scores["平均分"] = scores[["数学", "英语", "物理"]].mean(axis = 1)
print(scores)
# 输出：
#    姓名  数学  英语  物理   总分     平均分
# 0  张三  85  90  75  250  83.333
# 1  李四  92  88  80  260  86.667
# 2  王五  78  85  88  251  83.667
# 3  赵六  88  92  85  265  88.333
# 4  钱七  95  80  90  265  88.333
```

#### 找出数学成绩高于90分或英语成绩高于85分的学生    
```python
print(scores[(scores.数学 > 90) | (scores.英语 > 85)])
# 输出：
#    姓名  数学  英语  物理   总分     平均分
# 0  张三  85  90  75  250  83.333
# 1  李四  92  88  80  260  86.667
# 3  赵六  88  92  85  265  88.333
# 4  钱七  95  80  90  265  88.333
```

#### 按总分从高到低排序，并输出前3名学生
```python
sorted_scores = scores.sort_values(by = ["总分"], ascending = False)
print(sorted_scores.head(3))
```
