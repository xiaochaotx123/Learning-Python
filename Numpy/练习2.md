题目 5：数组变形
创建一个 1 到 12 的一维数组，并转换为 (3, 4) 的二维数组
- 计算每行的和与每列的平均值
- 将数组展平为一维数组
```python
import numpy as np
arr = np.arange(1, 13)
arr1 = np.reshape(arr, (3, 4))
print(arr1)
print(f"计算每行的和：{np.sum(arr1, axis = 1)}")
print(f"计算每列的平均数：{np.round(np.mean(arr1, axis = 0), 3)}")
arr2 = np.reshape(arr1, (12))
print(f"将数组展平为一维数组：{arr2}")
```

题目 6：布尔索引
生成一个 (5, 5) 的随机数组，范围 [0, 20)
- 找出数组中大于 10 的元素
- 将所有大于 10 的元素替换为0
```python
import numpy as np
arr = np.random.randint(0, 20, (5, 5))
print(arr)

print(f"找出数组中大于10的元素：{arr[arr > 10]}")
# arr[arr > 10] = 0
# print(arr)
print(f"将所有大于10的元素替换为0：{np.where(arr > 10, 0, arr)}")
```

题目 7：统计函数应用
某公司 6 个月的销售额（万元）为 [120, 135, 110, 125, 130, 140]
- 计算销售额的总和、均值和方差
- 找出销售额最高的月份和最低的月份
```python
import numpy as np
arr = np.array([120, 135, 110, 125, 130, 140])
print(f"销售额的总和：{np.round(np.sum(arr), 3)}")
print(f"销售额的均值：{np.round(np.mean(arr), 3)}")
print(f"销售额的方差：{np.round(np.var(arr), 3)}")
# 注意：argmax() 返回的是最大值的索引，需要加1, argmin()同理
print(f"销售额最高的月份：{np.argmax(arr) + 1}")
print(f"销售额最低的月份：{np.argmin(arr) + 1}")
```


题目 8：数组拼接
给定 A = [1, 2, 3] 和 B = [4, 5, 6]
- 将 A 和 B 水平拼接为一个新数组
- 将 A 和 B 垂直拼接为一个新数组
```python
import numpy as np
A = np.array([1, 2, 3])
B = np.array([4, 5, 6])
arr = np.concatenate([A, B])
print(f"A 和 B 水平拼接的数组：{arr}")
arr1 = np.reshape(arr, (2, 3))
print(f"A 和 B 垂直拼接的数组：{arr1}")
```

题目 10：综合应用
某商店 5 天的销售额（万元）和成本（万元）如下：
销售额：[20, 25, 22, 30, 28]
成本：[15, 18, 16, 22, 20]
- 计算每天的利润（销售额 - 成本）
- 计算利润的平均值和标准差
- 找出利润最高的天数
```python
import numpy as np
sell_arr = np.array([20, 25, 22, 30, 28])
cost_arr = np.array([15, 18, 16, 22, 20])
profit_arr = sell_arr - cost_arr
print(f"每天的利润：{profit_arr}")
print(f"利润的平均值：{np.round(np.mean(profit_arr), 3)}")
print(f"利润的标准差：{np.round(np.std(profit_arr), 3)}")
print(f"利润最高的天数：{len(profit_arr[profit_arr == np.max(profit_arr)])}")
# 因为np.argmax()返回最大值的索引，如果有多个最大值，那么会返回第一个最大值的索引，所以使用len(profit_arr) - np.argmax(profit_arr)就是利润最高的天数
```
