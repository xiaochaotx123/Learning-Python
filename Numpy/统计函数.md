```python
arr = np.random.randint(1, 10, 10)
```

```md
方差和标准差是表述数据离散程度(即数据偏离均值的程度)的两个核心统计量
方差：每个数据点与平均数之差的平方的平均数，用来衡量数据的波动大小
      特点是：单位是原始数据单位的平方(例如身高cm, 方差就是cm^2)
             方差越大，数据波动越大；方差为0表示所有数据相同
标准差：方差的平方根，用来衡量数据的波动大小
       特点是：单位是原始数据单位
              是实际应用中最常用的离散程度指标
```
```python
# 计算方差和标准差 np.var(), np.std()
arr = np.random.randint(1, 10, 10)
print(arr)
print(np.var(arr))

sum, ave, fangcha = 0, 0, 0
for i in range(0, len(arr), 1):
    sum += arr[i]
ave = sum / len(arr)
for i in range(0, len(arr), 1):
    fangcha += np.power((arr[i] - ave), 2)
fangcha = fangcha / len(arr)
print(fangcha)

print(np.std(arr))
print(np.sqrt(np.var(arr)))
```

```python
# 计算最大值、最小值 np.max(), np.min()
arr = np.random.randint(1, 101, 10)
print(np.max(arr), np.min(arr))
min_num = arr[0]
max_num = arr[0]
for i in range(0, len(arr), 1):
    min_num = min(min_num, arr[i])
    max_num = max(max_num, arr[i])
print(max_num, min_num)
```

```md
分位数是将数据按比例分成若干份，每份的数就是分位数，例如70分位数就是第70%的数据。
其中，分位数的计算方法是：将数据排序后，找到第p%的数据，就是第p%分位数
第50分位数就是中位数，第25分位数就是下四分位数，第75分位数就是上四分位数
```
```python
# 分位数 np.percentile()
arr = np.random.randint(10, 101, 10)
print(arr)
arr = np.sort(arr)
print(arr)
print(np.percentile(arr, 70))
print(arr[6] + (arr[7] - arr[6]) * 0.3)
```
