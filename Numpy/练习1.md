题目 1：温度数据分析
某城市一周的最高气温（°C）为 [28, 30, 29, 31, 32, 30, 29]。
- 计算平均气温、最高气温和最低气温
- 找出气温超过30°C的天数
```python
import numpy as np
temps = np.array([28, 30, 29, 31, 32, 30, 29])
print(f"平均气温：{np.round(np.mean(temps), 3)}°C")
print(f"最高气温：{np.max(temps)}°C")
print(f"最低气温：{np.min(temps)}°C")
print(f"气温超过30°C的天数：{np.sum(np.where(temps > 30, 1, 0))}")
"""
求气温超过30°C的天数还是有很多方法的
len(temps[temps > 30])
np.cumsum(np.where(temps > 30, 1, 0))[-1]
np.count_nonzero(temps > 30)
```
题目 2：学生成绩统计
某班级 5 名学生的数学成绩为 [85, 90, 78, 92, 88]。
- 计算成绩的平均分、中位数和标准差
- 将成绩转换为十分制（假设满分为10）
```python
import numpy as np

score = np.array([85, 90, 78, 92, 88])
print(f"平均分：{np.round(np.mean(score), 3)}")
print(f"中位数：{np.round(np.median(score), 3)}")
print(f"标准差：{np.round(np.std(score), 3)}")
print(f"十分制成绩：{np.round(score / 10, 3)}")
```

题目 3：矩阵运算
给定矩阵 A = [[1, 2], [3, 4]] 和 B = [[5, 6], [7, 8]]
- 计算 A + B 和 A * B（逐元素乘法）
- 计算 A 和 B 的矩阵乘法（点积）
```python
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(f"A + B：{A + B}")
print(f"A * B：{A * B}")
print(f"A 和 B 的矩阵乘法：{A @ B}")
# 或者使用 np.dot(A, B)
```

题目 4：随机数据生成
生成一个 (3, 4) 的随机整数数组，范围 [0, 10)
- 计算每列的最大值和每行的最小值
- 将数组中所有奇数替换为 -1
```python
import numpy as np
arr = np.random.randint(0, 10, (3, 4))
print(arr)
print("计算每列的最大值：")
for i in range(0, 4):
    print(f"第{i + 1}列的最大值为：{np.max(arr.T[i])}")
print("计算每行的最小值：")
for i in range(0, 3):
    print(f"第{i + 1}行的最小值为：{np.min(arr[i])}")
print("将数组中所有奇数替换为 -1：")
farr = np.where(arr % 2 == 1, -1, arr)
# 也可以直接是arr[arr % 2 == 1] = -1
print(farr)
# 在计算每列的最大值和每行的最小值的时候，没有使用np.max()和np.min()
# 因为直接使用np.max()和np.min()会返回整个数组的最大值和最小值
# 但是np.max()和np.min()可以制定轴，来计算每列或每行的最大值和最小值
# 后面一个参数是axis, axis的意思是轴，0表示列，1表示行
# 所以np.max(arr, axis = 0)可以返回每列的最大值，np.min(arr, axis = 1)可以返回每行的最小值
